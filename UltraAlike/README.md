# UltraAlike

A reproduction inspired by the E-mu Ultra samplers (the EOS 4 generation: E4XT Ultra, E5000 Ultra, E6400 Ultra and
their kin), to be a SynthLib plug-in (VST3 + AU) like the other Alikes.

**Placeholder (2026-11-14).** OneShot's skeleton under a new name and identifiers (VST3 and `aumu Ultr CPur`): it
builds, installs and plays a sample as OneShot does, beside it. The sampler itself is still to come; see
`Docs/design.md`. Not yet in `do-plugins` or `do-release`.
