# Program format

A program is two SysEx messages, both after `F0 00 20 29 01 24 <device>`: a main dump (command 02, 297 bytes) and an extension (command 1F, 99 bytes). Each carries bank and program number next, so field offsets below count from byte 10 of the message; bytes 10-25 of the main dump are the name.

Mask and shift are given where a byte holds several fields. A field in both dumps uses the extension's value.
