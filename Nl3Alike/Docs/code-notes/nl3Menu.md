# nl3Menu.c - the menu bar

File, Presets, Controls (how a drag turns a dial) and Help (the panel, About), as Pulse2Alike's.

## 1. Presets
Pulse2Alike's Presets menu over 1:001-8:128: Load, Store to the preset the sound came from, Store to a chosen one,
Revert, Import from a file or a folder, Export. Pulse2Alike's Pulse 2 menu (link, backup) has no counterpart yet - it
comes with the hardware link (design.md §6).

## 2. Sort
The order the preset browser lists in - Bank / Location or A-Z, shared with every Alike and remembered - and that
Prev/Next step through, wrapping (2026-11-12, as TiAlike). With no categories here, a Category order chosen in
another plug-in lists by bank and location.
